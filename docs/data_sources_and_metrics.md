# 데이터 출처 및 산출 지표 근거

본 문서는 Local Synergy Maker MVP에서 사용한 데이터 출처, 전처리 방식, 핵심 산출 지표의 계산 근거를 정리한 보조 문서이다. 제출용 본문에는 핵심 내용만 요약하고, 세부 산식과 데이터 처리 기준은 본 문서를 통해 보완 설명한다.

## 1. 데이터 활용 범위

본 프로젝트는 거제시를 MVP 실증 지역으로 선정하고, 관광 수요, 대중교통 공급, 상권 다양성, 관광지 좌표를 결합해 관광지별 정책 개입 우선순위를 산출한다. 분석 단위는 거제시 주요 관광 거점이며, 현재 MVP는 다음 7개 지점을 대상으로 한다.

| 구분 | 분석 대상 |
|---|---|
| 도심 허브 | 고현시외버스터미널 |
| 외곽 관광지 | 바람의 언덕 / 신선대, 매미성, 학동 흑진주 몽돌해변, 거제 파노라마 케이블카, 거제 정글돔 / 식물원 |
| 도심 관광 상권 | 거제 고현시장 |

## 4. 전처리 흐름

전처리 스크립트는 `src/analysis/process_data.py`이다.

1. 한국관광 데이터랩 CSV를 로드해 거제시 인기 관광지 순위와 평균 체류시간을 확인한다.
2. 소상공인시장진흥공단 경남 상가 데이터에서 `시군구명 == 거제시`인 업소만 필터링한다.
3. 거제시 업소를 행정동별로 묶고 업종 중분류 비중을 계산해 CEI를 산출한다.
4. 거제시 버스 시간표 Excel에서 관광지 접근에 필요한 정류장명, 노선번호, 운행 시각을 추출한다.
5. 관광지별 배차 간격, 관측 운행 횟수, 평균 간격, 최대 간격, 첫차, 막차, 노선번호를 요약한다.
6. SGIS OpenAPI로 관광지 도로명주소를 위경도로 변환한다.
7. API 호출 실패 시 검증된 도로명주소 기반 fallback 좌표를 적용한다.
8. 관광 수요, Tmap 순위, 버스 공급, 도보 접근성을 결합해 TII를 계산한다.
9. 최종 데이터를 `geoje_real_spots.csv`와 `bus_schedule_summary.csv`로 저장한다.

## 5. TII 산식 근거

### 5.1 지표 정의

TII(Tourism Isolation Index)는 관광 수요 대비 대중교통 공급이 부족한 정도를 나타내는 교통 고립도 지표이다. 값이 높을수록 관광객 관심도와 방문 수요는 크지만, 대중교통 접근성이 낮아 정책 개입 필요성이 큰 지점으로 해석한다.

### 5.2 반영 변수

| 변수 | 의미 | 반영 방향 |
|---|---|---|
| `visitors_monthly` | 월간 방문객 규모 추정값 | 클수록 TII 상승 |
| `tmap_search_rank` | 한국관광 데이터랩 인기 관광지 순위 | 순위가 높을수록 수요 압력 상승 |
| `bus_interval_min` | 관광지 접근 버스 배차 간격 | 길수록 공급 부족 |
| `bus_routes_count` | 접근 가능 노선 수 | 많을수록 공급 개선 |
| `walk_distance_m` | 정류장에서 관광지까지 도보 거리 | 길수록 라스트마일 접근성 저하 |

### 5.3 구현 산식

```text
rank_weight = 1 / log2(tmap_search_rank + 2)
tii_demand_pressure = visitors_monthly * rank_weight

bus_frequency_per_hour = (bus_routes_count * 60) / bus_interval_min
last_mile_access_index = 1000 / walk_distance_m
tii_supply_index = bus_frequency_per_hour * last_mile_access_index

tii_raw_score = tii_demand_pressure / tii_supply_index
tii_log_score = log1p(tii_raw_score)
tii_score = tii_log_score를 관광지 구간 기준 0.20~0.95로 정규화
```

도심 허브인 고현시외버스터미널은 관광지 고립도 비교 대상이 아니므로 `tii_score = 0.12`로 별도 설정한다.

### 5.4 해석 기준

| TII 구간 | 상태 | 해석 |
|---|---|---|
| 0.65 이상 | `isolated` | 관광 수요 대비 대중교통 공급이 부족한 우선 개선 후보 |
| 0.65 미만 | `normal` | 상대적으로 접근성 병목이 낮은 지점 |
| 허브 | `hub` | 출발 거점 또는 도심 교통 기준점 |

TII는 절대적인 교통 혼잡 지표가 아니라, MVP 내부 관광지 간 우선순위를 비교하기 위한 상대 지표이다.

## 6. CEI 산식 근거

### 6.1 지표 정의

CEI(Commercial Entropy Index)는 관광지 주변 행정동 상권의 업종 다양성을 나타내는 지표이다. 소상공인시장진흥공단 상가업소 데이터의 업종 중분류 분포를 사용해 섀넌 엔트로피를 계산하고, 업종 수에 따른 최대 엔트로피로 나누어 0~1 범위로 정규화한다.

### 6.2 구현 산식

```text
p_i = 특정 행정동 내 i번째 업종 중분류 업소 수 / 해당 행정동 전체 업소 수
H = -Σ(p_i * log2(p_i))
H_max = log2(해당 행정동 내 업종 중분류 수)
CEI = H / H_max
```

### 6.3 해석 기준

| CEI 값 | 해석 |
|---|---|
| 낮음 | 특정 업종 편중이 강하고 관광객 소비 선택지가 제한될 가능성 |
| 높음 | 업종 구성이 다양해 체류와 소비 확장 가능성이 상대적으로 높음 |

CEI는 읍면동 단위 상권 구조를 반영하므로, 실제 관광지 반경 500m 또는 1km 내 상권만을 정밀 분석한 값은 아니다. 향후에는 관광지 좌표 기준 공간 버퍼 분석으로 고도화할 수 있다.

## 7. 버스 시간표 산출 기준

버스 접근성은 거제시 시내버스 시간표 Excel을 읽어 관광지별 접근 정류장과 노선을 기준으로 산출한다.

| 관광지 | 기준 정류장/노선 | 산출 방식 | 현재 결과 |
|---|---|---|---|
| 바람의 언덕 / 신선대 | 해금강 정류장, 55/55-1 | Excel 자동 추출 | 배차 125분, 관측 7회 |
| 매미성 | 매미성 직접 정류장 | 직접 정류장명 미검출로 fallback | 배차 95분 |
| 학동 흑진주 몽돌해변 | 학동 정류장, 55/67/67-1 | Excel 자동 추출 | 배차 65분, 관측 13회 |
| 거제 파노라마 케이블카 | 거제케이블카승강장 경유 55번 계열 | Excel 자동 추출 | 배차 120분, 관측 4회 |
| 거제 정글돔 / 식물원 | 식물원/외간교회 정류장, 50-2 | Excel 자동 추출 | 배차 120분, 관측 7회 |

자동 추출이 어려운 지점은 기존 조사 기준값을 fallback으로 유지하고, `bus_schedule_source`와 `bus_schedule_note`에 근거를 남긴다. 이 방식은 자동화 과정에서 데이터 누락을 숨기지 않고, 추후 원천 시간표 구조가 개선되면 재산출할 수 있도록 설계한 것이다.

## 8. SGIS 좌표 보정 기준

관광지 좌표는 `src/analysis/sgis_geocoder.py`에서 다음 순서로 결정한다.

1. 관광지별 도로명주소를 SGIS OpenAPI에 전달한다.
2. SGIS 지오코딩 결과가 UTM-K 계열 좌표로 반환되면 좌표변환 API를 통해 WGS84 위경도로 변환한다.
3. SGIS 호출 또는 좌표변환이 실패하면 `VERIFIED_SPOT_REGISTRY`에 저장된 fallback 좌표를 사용한다.
4. 최종 좌표 출처는 `coord_source` 컬럼에 기록한다.

이 구조를 통해 지도 시각화에서 관광지가 바다나 산 외부로 크게 벗어나는 문제를 줄이고, API 장애 상황에서도 화면이 비어 보이지 않도록 했다.

## 9. 정책 시뮬레이션 근거

### 9.1 셔틀 투입 시뮬레이션

셔틀 시뮬레이션은 기존 대중교통 배차 간격과 신규 셔틀 공급을 비교해 대기시간 단축 효과를 산출한다.

```text
new_interval_min = max(15, round(70 / shuttle_count))
time_saved_percent = (original_interval_min - new_interval_min) / original_interval_min * 100
expected_new_visitors = visitors_monthly * time_saved_percent * 0.35
carbon_reduction_kg = expected_new_visitors * 0.4 * 2.5
```

- 왕복 70분은 MVP에서 셔틀 1대의 기본 순환 시간으로 둔 정책 시나리오 값이다.
- 최소 배차 15분 제한은 과도하게 낙관적인 배차 결과를 막기 위한 하한값이다.
- 추가 방문객과 탄소 저감량은 실측 예측값이 아니라 정책 대안 간 상대 비교용 추정값이다.

### 9.2 상권 다양성 시뮬레이션

상권 시뮬레이션은 선택 업종과 신규 점포 수에 따라 CEI 변화량을 가정하고, 체류시간 증가 효과를 회귀식 형태로 추정한다.

| 지원 업종 | CEI 변화 방향 | 정책 해석 |
|---|---|---|
| 로컬 특산물 F&B | 상승 | 지역 고유 소비 경험 강화 |
| 해양 공방/로컬 굿즈 | 상승 | 기념품, 체험 소비 확장 |
| 독립서점/복합문화공간 | 상승 | 체류형 문화 소비 유도 |
| 복제형 프랜차이즈 | 하락 | 상권 획일화 심화 가능성 |

체류시간 증가 추정식은 `src/analysis/regression_weights.json` 또는 기본 계수에 따라 다음 형태로 사용된다.

```text
ΔStay = 2.13 * ΔInterval + 411.8 * ΔCEI + 121.9 * ΔVacancy + 10.06
```

현재 MVP에서는 이 값을 실측 학습 완료 모델의 확정 예측이 아니라, 정책효과 방향성과 상대 크기를 비교하기 위한 시나리오 산식으로 해석한다.

## 10. 현재 한계와 보완 계획

| 항목 | 현재 상태 | 보완 방향 |
|---|---|---|
| 공간 상권 범위 | 읍면동 단위 CEI | 관광지 반경 500m/1km 버퍼 기반 상권 분석 |
| 공실률 | 과거 실험 산출물 존재, 현재 API 직접 반영 제외 | 공식 공실률 또는 현장 조사 데이터 연계 후 재반영 |
| 체류시간 효과 | 시나리오 산식 기반 추정 | 셔틀 운영 후 실제 방문자, 소비, 체류 로그로 검증 |
| 버스 시간표 | Excel 자동 추출 + 일부 fallback | 정류장 표준 ID 및 GTFS 형식으로 고도화 |
| 분석 지역 | 거제시 주요 관광 거점 7개소 | 통영, 남해, 여수, 강릉 등 관광도시 확장 |
