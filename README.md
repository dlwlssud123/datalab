# Local Synergy Maker

한국관광 데이터랩과 공공데이터를 활용해 관광지의 교통 고립과 주변 상권 획일화 문제를 함께 진단하는 정책 의사결정 지원 MVP입니다. 거제시를 실증 지역으로 삼아 관광 수요, 버스 배차, 상권 업종 분포, 관광지 좌표를 결합하고, 셔틀 투입 및 로컬 상권 지원 정책의 효과를 웹 화면에서 비교할 수 있도록 구현했습니다.

## 프로젝트 배경

본 프로젝트가 다루는 문제는 거제시에만 국한되지 않습니다. 전국의 많은 관광지는 도심이나 교통 거점에서 떨어진 외곽 명소를 보유하고 있지만, 대중교통 배차 간격이 길거나 환승이 복잡해 비자차 관광객의 접근성이 낮습니다. 또한 관광지 주변 상권이 카페, 음식점, 숙박 등 유사 업종 중심으로 반복되면서 지역 고유의 소비 경험과 체류 유인이 약해지는 문제도 여러 관광지에서 공통적으로 나타납니다.

거제시를 MVP 실증 지역으로 선정한 배경은 개인적인 관광 경험과 문화 콘텐츠를 통한 지역 관심에서 출발했습니다. 타지에서 보았던 유사한 상점이 거제 관광지 주변에서도 반복되는 것을 보며 관광 상권의 획일화를 체감했고, 거제 여행 중에는 긴 배차 간격, 복잡한 환승, 택시 의존 부담 등 비자차 관광객의 이동 불편을 직접 경험했습니다. 또한 리센느를 통해 거제라는 지역에 관심을 갖게 되었고, 실제 관광 경험에서 느낀 문제를 데이터로 검증해보고자 했습니다.

거제시는 바람의 언덕, 매미성, 학동 흑진주 몽돌해변, 거제 정글돔 등 외지인 관심도가 높은 관광 자원을 보유하면서도 외곽 관광지 접근성 부족과 주변 상권 다양성 문제를 함께 관찰할 수 있어, 전국 관광지 공통 문제를 검증하기 위한 MVP 대상지로 적합하다고 판단했습니다.

## 핵심 목표

- 인기 관광지를 단순히 홍보하는 것이 아니라, 이미 수요가 있는 관광지의 교통 병목과 상권 약점을 데이터로 찾습니다.
- 교통과, 관광과, 지역경제과가 함께 볼 수 있는 통합 의사결정 지표를 제공합니다.
- 셔틀 투입, 로컬 창업 지원 등 정책 개입 시나리오별 상대 효과를 비교합니다.
- 거제시 MVP를 바탕으로 통영, 남해, 여수, 강릉 등 다른 관광도시로 확장 가능한 구조를 제시합니다.

- 로컬 업종 입점 지원에 따른 상권 다양성 변화 시뮬레이션

- AI Gateway 기반 정책 제언서 생성 기능

## 핵심 지표

### TII: Tourism Isolation Index

TII는 관광 수요 대비 대중교통 공급이 부족한 정도를 나타내는 교통 고립도 지표입니다. 값이 높을수록 관광 수요는 크지만 대중교통으로 접근하기 어려운 관광지로 해석합니다.

반영 요소:

- 월간 관광 수요 추정치
- Tmap 검색 순위
- 버스 배차 간격
- 버스 노선 수
- 정류장-관광지 도보거리

현재 구현 산식:

```text
관광수요압력 = 월간 방문객 / log2(Tmap 순위 + 2)
대중교통공급지수 = 시간당 버스 공급량 × 라스트마일 접근성
TII 원점수 = 관광수요압력 / 대중교통공급지수
최종 TII = log1p(TII 원점수)를 0.20~0.95 구간으로 정규화
```

### CEI: Commercial Entropy Index

CEI는 관광지 주변 상권의 업종 다양성을 나타내는 지표입니다. 소상공인 상가업소 데이터의 업종 분포를 바탕으로 섀넌 엔트로피를 계산하고 0~1 범위로 정규화합니다.

값이 낮을수록 특정 업종에 편중된 상권이고, 값이 높을수록 다양한 소비 선택지가 있는 상권입니다.

```text
CEI = -Σ(p_i × log2(p_i)) / log2(업종 수)
p_i = 해당 읍면동 내 i번째 업종 비중
```

## 분석 및 처리 흐름

1. `data/raw`의 한국관광 데이터랩 CSV와 공공데이터를 로드합니다.
2. 소상공인 상가업소 데이터에서 거제시 업소만 추출합니다.
3. 읍면동별 업종 분포를 계산해 CEI를 산출합니다.
4. 거제시 버스 시간표 Excel에서 관광지별 주요 노선 운행 시각을 추출합니다.
5. 각 관광지의 배차 간격, 관측 운행 횟수, 첫차·막차, 노선 정보를 산출합니다.
6. SGIS OpenAPI로 관광지 도로명주소를 위경도로 변환합니다.
7. API 실패 시 검증된 도로명주소 기반 fallback 좌표를 적용합니다.
8. 관광 수요, 교통 공급, 도보거리 정보를 결합해 TII를 계산합니다.
9. 최종 가공 데이터를 `data/processed/geoje_real_spots.csv`로 저장합니다.

## 주요 관광지 분석 대상

- 고현시외버스터미널: 도심 교통 허브
- 바람의 언덕 / 신선대: 남부면 외곽 대표 관광지
- 매미성: 장목면 외곽 포토스팟
- 학동 흑진주 몽돌해변: 동부면 자연 관광지
- 거제 파노라마 케이블카: 동부면 산악 레저 관광지
- 거제 고현시장: 도심 전통시장
- 거제 정글돔 / 식물원: 거제면 실내 관광지

## 정책 시뮬레이션

### 교통 시뮬레이션

사용자가 관광지와 셔틀 투입 대수를 선택하면 기존 버스 배차 간격 대비 신규 셔틀 배차 간격을 계산합니다. 이를 바탕으로 대기시간 단축률, 예상 추가 방문객, 탄소 저감 효과를 추정합니다.

### 상권 시뮬레이션

사용자가 지원 업종과 입점 점포 수를 선택하면 해당 읍면동의 CEI 변화와 체류시간 증가 추정치를 계산합니다. 지원 업종은 로컬 F&B, 해양 공방 및 로컬 굿즈, 독립서점 및 복합문화공간, 복제형 프랜차이즈로 구성됩니다.

### 체류시간 증가 추정

현재 체류시간 증가는 실측 장기 패널데이터로 검증된 확정 예측값이 아니라, 정책 개입 시나리오 간 상대 효과를 비교하기 위한 추정값입니다.

```text
ΔStay = 2.13 × ΔInterval + 411.8 × ΔCEI + 121.9 × ΔVacancy + 10.06
```

따라서 결과는 정책 대안별 효과 크기 비교를 위한 참고 지표로 해석해야 합니다.

## 한계 및 향후 개선

- 체류시간 증가는 실측 검증 예측값이 아니라 정책효과 시나리오 추정값입니다.
- 현재 MVP는 거제시 주요 관광 거점 7개소 중심으로 구성되어 있습니다.
- 관광지 반경 500m~1km의 정확한 공간 상권 분석은 향후 고도화가 필요합니다.
- 공실률 데이터는 향후 실시간 또는 분기별 공식 통계와 재연계하여 정책효과 산정에 반영할 예정입니다.
- 실제 셔틀 운영 후 방문객 변화, 카드 소비, 상권 매출 데이터를 확보하면 모델 신뢰도를 높일 수 있습니다.

서식4 제출 문서에는 이 프로젝트를 “전국 관광지 공통 문제를 해결하기 위한 거제시 MVP 실증 사례”로 설명하는 것이 적합합니다. 핵심 메시지는 다음과 같습니다.

```text
본 프로젝트는 인기 관광지를 더 홍보하는 서비스가 아니라,
이미 수요가 존재하는 관광지의 교통 병목과 상권 약점을 데이터로 찾아
정책 개입 우선순위를 제안하는 시스템이다.
```
