# 🌊 Local Synergy Maker (거제시 실증 모델)
> **한국관광 데이터랩 빅데이터 기반 교통 고립지 해소 및 상권 다양성 시뮬레이션 솔루션**  
> *2026 한국관광 데이터랩 활용 경진대회 출품 프로젝트*

---

## 📌 프로젝트 소개
외지 관광객의 잠재 수요 대비 대중교통 인프라가 단절된 외곽 관광지를 발굴하는 **'교통 고립지 지수(TII)'**와, 전국 상권의 획일화(클론화)를 진단하고 로컬 고유 상점을 매칭하는 **'상권 엔트로피 지수(CEI)'**를 자체 개발하여, 지자체의 관광 셔틀 증차 및 공실 해소 정책을 지원하는 B2G 의사결정 시뮬레이션 플랫폼입니다.

* **실증 대상 도시**: 경상남도 거제시
* **핵심 타깃**: 외곽 2차 교통망 단절 지역(남부면 바람의 언덕·신선대, 장목면 매미성 등)

## 🚀 빠른 시작 (개발 예정)
```bash
# 가상환경 생성 및 활성화
python -m venv .venv
.venv\Scripts\activate

# 패키지 설치
pip install -r requirements.txt

# 대시보드 실행
streamlit run src/app/main.py
```
